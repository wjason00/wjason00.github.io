Model Morpher · Python 3D surface tool

Dentate gyrus →to whole mouse brain

I built Model Morpher in Python to compute smooth intermediate shapes between two 3D meshes that do not share matching vertices. It turns each surface into a signed distance field, blends the fields and extracts new meshes along the transition — shown here across 30 saved surfaces from the Allen Mouse CCF via BrainGlobe (Allen Institute).

Method, data credit and provenance
  • Atlas meshes: dentate gyrus (726) and whole-brain root (997), Allen Mouse CCF v1.2 at 25 µm via BrainGlobe (Allen Institute; Wang et al. 2020, doi:10.1016/j.cell.2020.04.007).
  • Pipeline: mesh repair → 128³ signed distance field sampling → field interpolation → marching-cubes surface extraction (f14ee06, target 15,000 faces; all 30 frames returned).
  • Display: 2,048 vertices sampled deterministically per saved mesh under one shared camera scale. Optional cross-fading blends opacity between neighbouring frames for 160 ms without inventing intermediate coordinates.
  • Records: point-sample manifest (JSON) · capture manifest (JSON) · licences & notices.
