      What this pilot tests

      The intact model is compared with two interventions: zero only the direct left Roundup → MN9 edge, or zero all outgoing weights of left Roundup. Incoming connections remain. The direct intervention is source neuron 720575940623211725 to MN9 720575940660219265.

      Aligned input shares a template across the 21 input channels. The second pattern uses circularly shifted copies. This is a comparison of artificial timing schedules, not recorded biological input.

      The full published model runs at gain 1 and a 0.1 ms step for 1.5 seconds, with a 500 ms periodic input schedule repeated three times. The 500 ms analysis window follows a 500 ms warmup. Only simulated neural output is measured; there is no biological validation or prediction of body movement.
